\chapter{绪论}

\section{研究背景与意义}

时空序列预测是指利用历史时刻的观测值及其所附带的时间戳、空间位置或拓扑关系等信息，预测未来一段时间内多个变量或空间节点取值的数据挖掘任务。它既是时间序列预测与图数据学习的交叉问题，也是智慧城市、智能交通、能源管理、气象预报、工业监测和金融风控等实际应用中的基础性任务\cite{traffic-stf-survey,gnn4ts,survey01}。随着物联网、移动传感和城市数字化程度的不断提高，各类业务系统持续产生海量、高频、高维且高度耦合的时空数据。对这些数据进行准确预测，不仅有助于提前识别交通拥堵、设备异常和供需波动等风险，也能为资源调度、运营决策和风险控制提供重要依据，因而具有突出的理论价值与现实意义。

按照数据中是否显式给定空间图结构，时空序列预测可以大致划分为两类典型问题。一类是面向一般多元时间序列的预测任务，其输入通常为多个通道同步采集的时间序列，如电力负荷、汇率、气象要素等，变量之间可能存在隐含的相关关系；另一类是以交通流预测为代表的空间图时间序列预测任务，其输入通常对应交通路网中的若干传感器或路段节点，节点之间通过预先给定或可学习的邻接矩阵表达空间连接关系。两类任务在输入形式上有所区别，但都面临着若干共同挑战：观测数据往往呈现明显的非平稳性，统计特性随时间或空间尺度发生变化；序列中同时存在趋势、周期、局部波动等多尺度模式；不同通道或不同区域的数据分布存在显著差异；时空依赖既包含由物理连接决定的静态结构，也包含随时间演化的动态关系。

传统时间序列预测方法，如自回归移动平均模型、指数平滑和季节趋势分解等，基于较为明确的统计假设对序列进行建模，在平稳、低维和线性场景中具有良好的可解释性\cite{brockwell1991time,1990STL}。然而，现实时空序列通常具有非线性、长程依赖、高维耦合和非平稳等特点，使得传统方法的表达能力受到明显限制。近年来，以循环神经网络、卷积神经网络、图神经网络和 Transformer 为代表的深度学习方法被广泛应用于时空序列预测，并通过注意力机制、频域分析、实例归一化和多尺度分解等手段显著提升了预测精度\cite{wen2023transformers,gnn4ts,kim2024comprehensive}。尽管如此，现有方法在刻画时空序列内在异质性与尺度变化方面仍存在不足：多数模型采用单一尺度的特征提取方式，或对所有变量、所有节点共享同一组参数，难以自适应地处理不同尺度和不同分布模式；部分方法虽然引入多尺度结构，但尺度划分通常依赖经验或先验知识，无法根据当前输入动态调整；同时，对时间戳信息、静态拓扑与动态时空依赖的联合利用仍不充分。

混合专家（Mixture-of-Experts，MoE）机制为上述问题提供了一种自然的建模思路。其核心思想是针对输入样本或特征的分布差异，将其路由到若干具有专门化能力的专家网络中进行处理，再对专家输出进行加权融合，从而在不显著增加整体计算量的前提下提升模型对异构模式的适应能力\cite{moe,moe-survey}。时空序列中的非平稳性和异质性恰好与 MoE 的“分而治之”思想相契合：不同时间尺度、不同变量通道以及不同空间区域可以对应不同的专家，从而避免共享参数模型在分布差异较大时的表达能力退化。然而，如何针对时空序列设计合适的路由信号、专家结构、多尺度信息融合方式，以及如何同时建模静态与动态依赖，仍然是尚未充分解决的问题。

基于上述分析，本文围绕“多尺度建模”和“混合专家系统”两条主线展开研究，分别面向一般多元时间序列预测和交通流预测任务提出 BIM3 与 ADAMS-MoE 两个模型。前者聚焦时间维度的双向时间戳依赖、多尺度时序模式和通道间分布差异，提出双向时间感知建模与多尺度特征提取混合专家框架；后者聚焦空间维度的尺度非平稳性以及静态图结构与动态时空依赖的共存问题，提出自适应空间多尺度建模与静动态双混合专家框架。两个工作从时间域与空间域两个侧面共同验证了“多尺度建模 + 混合专家”在时空序列预测中的有效性，为构建更具适应性和鲁棒性的时空预测模型提供了新的技术路线。

\section{国内外研究现状}

\subsection{基于深度学习的多元时间序列预测方法}

早期多元时间序列预测主要依靠统计方法对变量之间的线性关系和季节性进行建模。随着深度学习的发展，研究者提出了大量面向多元时间序列预测的神经网络模型。以循环神经网络为基础的方法通过序列递归建模捕捉时间依赖\cite{deepar}；以卷积神经网络为基础的方法利用局部感受野提取时序特征\cite{micn,cnn_related1}；图神经网络方法将变量视为图节点，通过学习变量间关系提升预测能力\cite{cdotsgnn,mtgnn}。Transformer 的兴起进一步推动了长程时序建模的发展，Informer、Autoformer、PatchTST、Crossformer 和 iTransformer 等工作分别从稀疏注意力、序列分解、分块表示、跨维依赖和变量令牌化等角度改进时序 Transformer\cite{informer,autoformer,patchtst,crossformer,itransformer}。此外，DLinear 等工作指出，线性模型在部分时序预测基准上同样具有较强的竞争力，促使研究者更加关注模型归纳偏置与任务特性的匹配\cite{dlinear}。

针对时间序列中的多尺度结构，Pyraformer、SCINet、Pathformer 和 PDF 等方法通过金字塔注意力、二分下采样树、自适应分块和周期解耦等方式提取不同粒度的时序信息\cite{pyraformer,scinet,pathformer,pdf}。FITS、FreTS 和 FilterNet 等方法则从频域角度建模序列的周期与频率特性\cite{fits,frets,filternet}。与此同时，真实世界时间序列往往存在分布漂移和非平稳性，AdaRNN、Dish-TS 和 Non-stationary Transformers 等工作通过域适应、分布调整和去平稳化等方式缓解训练与测试分布不一致的问题\cite{adarnn,dishts,ns-trans}。时间戳作为时序数据的重要组成部分也逐渐受到关注：早期模型或者直接忽略时间戳，或者仅将其作为位置编码或辅助特征输入\cite{itransformer,timesnet}；GLAFF 和 TimeSter 等工作开始显式建模时间戳中包含的周期和趋势信息，以提升预测的鲁棒性和精度\cite{glaff,timester}。然而，上述方法通常将历史时间戳与未来时间戳分别处理，较少显式刻画二者之间的双向依赖；同时，多尺度模型往往在不同通道之间共享参数，难以充分捕捉不同变量在时间分布和多尺度模式上的异质性。

\subsection{交通流预测中的时空图建模方法}

交通流预测是时空序列预测中最具代表性的任务之一。由于交通传感器或路段之间具有天然的图结构，基于图神经网络的方法已成为主流。STGCN 将图卷积与时间卷积结合，首次系统地将时空图建模引入交通预测\cite{stgcn}；DCRNN 使用扩散卷积和编码器—解码器结构建模交通扩散过程\cite{dcrnn}；Graph WaveNet 在不需要显式邻接矩阵的条件下学习自适应图结构\cite{gwnet}。此后，ASTGCN、MTGNN、AGCRN、DGCRN、STID 和 STAEformer 等工作分别从注意力时空卷积、图结构学习、自适应图生成、动态图建模和时空嵌入等角度推进了交通预测方法的发展\cite{astgcn,mtgnn,agcrn,dgcrn,stid,staeformer}。

真实交通数据通常具有空间非平稳性，即不同空间尺度上的数据分布和依赖模式存在差异。为此，研究者提出了一系列空间多尺度方法。HGCN 通过谱聚类构造层次图，并在不同尺度上分别学习时空依赖\cite{hgcn}；STPGNN 利用节点相似性识别关键节点，构造新的邻接矩阵以提取双尺度特征\cite{stpgnn}；PyGNN 和 MAGNN 则从图采样、图过滤和多尺度自适应图学习等角度增强空间多尺度表示能力\cite{pygnn,magnn}。这类方法表明，将空间图划分为不同尺度进行分层建模有助于捕获从局部路网到区域交通的异质模式。但现有空间多尺度方法通常依赖距离、聚类或节点相似性等先验知识构造尺度，且大多只考虑原图和一个额外子图两个尺度，难以根据当前交通状态自适应地确定尺度数量和融合权重。与此同时，交通序列中静态路网结构和动态时空依赖往往同时存在。D2STGNN 等工作通过解耦静态与动态图卷积捕捉两类关系\cite{d2stgnn}；TESTAM 采用混合专家结构分别提取时间特征、静态图特征和动态图特征\cite{testam}；ST-MoE 将时空混合专家用于交通预测中的去偏建模\cite{st-moe}。不过，现有方法或者采用全激活的专家结构，计算开销较高，或者采用硬选择策略，难以在同一时间状态下联合建模静态结构与动态演化。

\subsection{多尺度建模与混合专家系统}

多尺度建模已在时序和时空预测中展现出明显优势。在时间维度上，不同粒度的时间序列往往分别携带趋势、季节和局部波动等信息，分层或并行处理多尺度表示有助于缓解单一尺度带来的信息损失\cite{pyraformer,pathformer,pdf}。在空间维度上，多尺度图表示能够刻画传感器网络从细粒度局部结构到粗粒度区域结构的非平稳模式\cite{hgcn,pygnn,magnn}。然而，简单地对所有尺度使用统一参数，或仅依赖人工设定的尺度数量，难以适应输入分布的变化。混合专家系统提供了一种自适应地组合多个子模型的方式。经典稀疏门控 MoE 通过 Top-$k$ 路由在大量专家中只激活少量专家，从而兼顾模型容量和计算效率\cite{moe}；SMoEs 将专家机制引入空间维度，用于处理空间输入中的局部差异性\cite{smoes}；ST-MoE 和 TESTAM 则开始将 MoE 应用于交通预测，以处理时空分布的非平稳性\cite{st-moe,testam}。总体来看，现有工作已经验证了多尺度表示和混合专家机制的有效性，但二者仍缺乏系统性的结合。尤其缺少一种既能在时间域中动态路由不同尺度、不同通道的模式，又能在空间域中自适应构造多尺度图并联合建模静态与动态依赖的 MoE 框架。本文的两个工作正是围绕这一缺口展开。

\section{本文的主要研究内容与贡献}

本文的核心研究问题可以概括为：在时空序列预测中，如何通过多尺度建模与混合专家系统，自适应地刻画数据在时间、变量和空间维度上的非平稳性与异质性，从而提升模型的预测精度和鲁棒性。围绕该问题，本文分别在一般多元时间序列预测和交通流预测两个代表性任务上开展研究，主要工作如下。

第一项工作针对一般多元时间序列预测任务，提出 BIM3 模型。现有方法往往忽视历史时间戳与未来时间戳之间的双向依赖关系，并且在多尺度时序建模时通常对所有通道共享参数，难以捕捉不同通道的数据分布差异。针对上述问题，BIM3 设计了时间戳双向交叉注意力模块（Timestamp Dual Cross-Attention Module，TDCAM），通过对称交叉注意力显式建模历史区间与未来区间之间的双向时间上下文，并将其作为约束融入预测过程；同时设计了多尺度特征提取混合专家模块（Multi-Scale Feature Extract Mixture-of-Experts，MSMoE），采用稀疏门控路由将不同通道的时序数据动态分配到若干专家中，每个专家对输入进行多尺度下采样、趋势—季节分解和跨尺度融合，从而实现对不同时间分布和多尺度模式的细粒度建模。此外，BIM3 还利用频域中的可学习马氏矩阵提取变量间相关关系，并引入辅助损失平衡专家负载。实验表明，BIM3 在 10 个真实世界数据集上取得了具有竞争力的预测性能，验证了双向时间戳建模和多尺度混合专家设计的有效性。

第二项工作针对交通流预测任务，提出 ADAMS-MoE 模型。真实交通数据同时存在由空间尺度变化引起的空间非平稳性和由交通状态演化引起的时间非平稳性，且静态路网结构与动态时空依赖相互耦合。针对这些问题，ADAMS-MoE 设计了空间多尺度混合专家模块（Spatial Multi-Scale Mixture-of-Experts，SMS-MoE），通过图池化以数据驱动方式构造多个空间尺度的子图，并利用尺度专家和自适应尺度融合机制提取尺度特异性特征；同时设计了静态—动态双混合专家模块（Static-Dynamic Dual Mixture-of-Experts，SD-MoE），其中静态图 MoE 使用轻量图卷积专家捕捉显式拓扑结构，动态图 MoE 使用节点级全注意力专家挖掘隐式时空依赖，并通过稀疏激活实现高效联合建模。最后，模型通过门控融合层将空间多尺度特征与静动态时空特征进行自适应融合。在 6 个公开交通数据集上的实验结果表明，ADAMS-MoE 能够一致地取得先进预测性能，验证了自适应空间多尺度建模和静动态双专家学习的有效性。

从整体研究脉络来看，BIM3 侧重从时间、时间戳和通道分布角度解决一般多元时间序列中的非平稳与多尺度问题；ADAMS-MoE 则将多尺度思想扩展到空间图结构，并进一步处理静态图与动态依赖共存的交通预测问题。二者共同构成了一套较为完整的“多尺度建模 + 混合专家”时空序列预测研究框架，分别从时间域和空间域验证了所提建模思想的通用性与有效性。

本文的主要贡献总结如下：

\begin{itemize}
    \item 提出 BIM3 模型，针对一般多元时间序列预测中历史与未来时间戳双向依赖利用不足的问题，设计时间戳双向交叉注意力模块，显式建模双向时间上下文并引入时间戳约束。
    \item 提出多尺度特征提取混合专家模块，利用稀疏门控路由和通道独立专家，对不同时间分布下的多尺度时序模式进行自适应建模，并通过频域马氏矩阵学习变量间相关关系。
    \item 提出 ADAMS-MoE 模型，面向交通流预测中的空间非平稳性，设计基于图池化的自适应空间多尺度混合专家模块，实现多尺度空间图的数据驱动构造与跨尺度自适应融合。
    \item 提出静态—动态双混合专家模块，通过轻量静态图专家和节点级动态注意力专家，在稀疏激活条件下联合建模交通路网的静态拓扑结构与动态时空依赖。
    \item 在多个公开的多元时间序列预测和交通流预测基准数据集上开展了系统实验，验证了所提模型和关键模块的有效性，并分析了不同尺度、专家数量和路由策略对预测性能的影响。
\end{itemize}

\section{本文章节组织}

本文围绕多尺度建模与混合专家系统在时空序列预测中的应用展开研究，全文共分为五章，各章内容安排如下。

第1章为绪论。本章介绍了时空序列预测的研究背景与意义，梳理了多元时间序列预测、交通流预测以及多尺度建模与混合专家系统等方面的国内外研究现状，分析了现有方法存在的不足，并概述了本文的主要研究内容与贡献。

第2章为相关理论基础。本章介绍与后续方法相关的预备知识，包括时间序列预测的基本问题定义、基于深度学习和图神经网络的时空序列预测方法、多尺度建模技术以及混合专家系统的路由与训练机制，为第3章和第4章的研究工作提供理论基础。

第3章介绍 BIM3 模型。本章面向一般多元时间序列预测任务，依次阐述问题定义、时间戳双向交叉注意力模块、多尺度特征提取混合专家模块、频域变量相关建模方法以及整体损失函数，并给出实验设置、与主流方法的对比结果、消融实验和参数分析。

第4章介绍 ADAMS-MoE 模型。本章面向交通流预测任务，阐述时空非平稳性问题、数据驱动的空间多尺度图构造、空间多尺度混合专家模块、静态—动态双混合专家模块和门控融合机制，并在多个交通预测基准数据集上验证模型性能及各模块的有效性。

第5章为总结与展望。本章对全文工作进行总结，归纳两个模型的研究结论和主要贡献，并讨论当前方法存在的不足以及未来可能的研究方向。
